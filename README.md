# Auto Login

1. Open **Tampermonkey → Dashboard → Utilities → Import from URL**.
2. Paste this URL and click **Install**:

   https://raw.githubusercontent.com/seemscloud/tampermonkey/main/auto-login.user.js

3. Open **Settings → Script Update → Check Interval** and select **Every day**, not **Never**.

Install only once. If Auto Login is already listed under **Installed Userscripts**, skip to step 3. Future versions download automatically when their `@version` increases. Refresh the service page after an update.
