# Auto Login

1. Otwórz **Tampermonkey → Panel → Narzędzia → Import z URL**.
2. Wklej ten adres i kliknij **Zainstaluj**:

   https://raw.githubusercontent.com/seemscloud/tampermonkey/main/auto-login.user.js

3. W ustawieniach Tampermonkey włącz automatyczne sprawdzanie aktualizacji skryptów, np. raz dziennie.
4. Wyłącz stare osobne skrypty Auto Login i odśwież stronę serwisu.

Gotowe — skrypt loguje automatycznie, a nowe wersje pobiera z GitHuba. Nie wklejasz kodu.
